# Backend Handoff Schema: `reports/fire_viirs_results.json`

**Schema version:** `1.0.0`  
**Primary consumer:** Backend API / frontend presentation layer (coordinated with G).  
**Generator:** `python -m src.fire_analysis`

## 1. JSON Contract & Nullability Rules

- **Strict RFC 8259 JSON (`allow_nan=False`):** `NaN`, `Infinity`, and `-Infinity` are forbidden anywhere in the file. Unavailable medians (e.g., months with zero detections), withheld percentage changes (`baseline <= 0` or missing), zero-variance correlation metrics, and unassessed inferential statistics serialize strictly as JSON **`null`**.
- **Units & terminology guardrail:** All numeric count fields represent **satellite hotspot detections** (`375 m` VIIRS pixel-center thermal anomalies per overpass), **NEVER** unique fires, burned hectares, or forest loss area. UI and API consumers must display `dataset.unit_caveat` alongside charts/metrics.
- **Region governance guardrail:** All sub-national boxes carry `"agreement_status": "proposed_pending_team_agreement"` (or `"proposed_for_review_not_validated_control"` in comparability records) until the team confirms study and reference regions.
- **Companion outputs generated by the same command:**
  - `reports/fire_monthly.csv` — `672` rows (`7 regions × 4 filter modes × 24 study months`), including `region_role` and `region_days_with_detections` in addition to the JSON fields
  - `reports/fire_regional_summary.csv` — `56` flat comparison rows (`7 regions × 4 filter modes × 2 seasonal windows`)
  - `reports/fire_comparability_matrix.csv` — `8` candidate study × candidate reference pre-2022 alignment rows
  - `reports/fire_quality.json` — detailed source hashes, validation row accounting, classification breakdown, missing-date inventory, and `0.01°` repeated-detection diagnostics
  - `reports/fire_location_map.png` & `reports/fire_monthly_comparison.png` — presentation figures

## 2. Top-Level Object Structure

| Key | Type | Description |
|---|---|---|
| `schema_version` | `string` | Semantic schema version (`"1.0.0"`). |
| `status` | `object` | Claim-level status flags: `overall`, `archive_verification`, `coordinate_and_time_validation`, `deduplication`, `proposed_region_agreement`, `before_after_significance`, `causal_attribution`. |
| `dataset` | `object` | Provider, `product`, `archive_series` (`"SV-C2"`), observed satellites/instruments/versions, `units`, `unit_caveat`, `study_months`, `study_years`, `observed_extent`, and `files_verified` (`archive_file`, `archive_sha256`, `csv_member`, `csv_sha256`, `raw_row_count`, `date_min`, `date_max`). |
| `quality_summary` | `object` | `accounting` (raw/dropped/retained counts), `validation_checks` (boolean integrity assertions), `classification_breakdown` (`type` and `confidence` overall and by year), and `confidence_filtering_sensitivity`. |
| `missing_observation_gaps` | `object` | Per-year missing-date counts (`2019`–`2022`), explicit `2022_missing_dates` array (`16` dates), `satellite_month_coverage` array (`24` months), and `gap_explanation`. |
| `repeated_detections_summary` | `object` | `0.01°` grid (`~1.1 km N–S × ~0.72 km E–W` at `49°N`) repeat diagnostics (`all_types_overall`, `type0_vegetation_overall`, `type0_vegetation_by_year`, `all_types_by_year`). |
| `proposed_regions` | `array<object>` | Full national export plus `6` candidate study/reference/cross-layer boxes with `region_id`, `name`, `role`, `bounding_box` (`south`, `north`, `west`, `east`), `description`, and `agreement_status`. |
| `pre_2022_comparability` | `array<object>` | `18`-month (`2019–2021` Mar–Aug) alignment metrics between candidate study and reference regions (`pre2022_pearson_r`, `pre2022_spearman_rho`, `standardized_anomaly_rmse`, `pre2022_level_ratio_study_to_ref`, `study_jun_aug_share_pre2022`, `ref_jun_aug_share_pre2022`, `comparability_tier`, `agreement_status`). |
| `regional_comparisons` | `object` | Nested dictionary keyed as `[region_id][filter_mode][window_id]` (`mar_aug` and `may_aug`), with yearly totals/rates, `baseline_2019_2021`, `target_2022`, `vs_baseline_2019_2021`, and `vs_2021_prior_year`. |
| `spatial_shift_highlights` | `object` | `0.25°` (`type=0`) grid shift summary (`grid_resolution_deg`, `total_populated_cells`, `cells_with_increase`, `cells_with_decrease`, `top_increases`, `top_decreases`). |
| `monthly_series` | `array<object>` | `672` monthly records with `month`, `year`, `calendar_month`, `region_id`, `filter_mode`, `detections`, `satellite_observed_days`, `calendar_days`, `satellite_coverage_fraction`, `detections_per_observed_day`, `unique_0_01deg_cell_days`, `day_detections`, `night_detections`, `frp_sum_mw`, and `frp_median_mw` (`number \| null`). |
| `statistics` | `object` | Holds `before_after_seasonal_inference` with `"status": "not_assessed"`, `p_value: null`, `ci_95_lower: null`, `ci_95_upper: null`, `statistical_significance_claimed: false`, and `reasons_not_assessed`. |
| `charts` | `object` | Relative paths and source descriptions for both PNG visuals and CSV tables. |
| `limitations` | `array<string>` | Mandatory interpretation guardrails for UI/API display. |
| `reproducibility` | `object` | Exact regeneration command (`python -m src.fire_analysis`), test command (`python -m unittest discover -s tests -v`), and documentation paths. |

## 3. Enumerations & Withheld Metric Semantics

- **`filter_mode` values:**
  - `type0_vegetation_all_conf` — primary open/vegetation fire mode (`type == 0`, all confidence levels `l/n/h`)
  - `type0_vegetation_nominal_high` — sensitivity mode (`type == 0`, `confidence in {'n', 'h'}`)
  - `all_types_all_conf` — unfiltered export (`types 0, 2, 3`, all confidence levels; mixes industrial flares with vegetation fires)
  - `type2_static_industrial` — static thermal sources sensitivity layer (`type == 2`)
- **`window_id` values:** `mar_aug` (full March–August 6-month window) and `may_aug` (May–August spring-burned exclusion sensitivity window).
- **`*_pct_status` values (`_safe_pct_change`):** `"computed"` | `"withheld_nonpositive_baseline"` | `"withheld_missing_data"` (for example, `kyiv_no2_box` under `type2_static_industrial` has `0` baseline detections and emits `null` with `"withheld_nonpositive_baseline"`).
- **`comparability_tier` values:** `"strong_pre2022_seasonal_alignment"` (`r >= 0.80`) | `"moderate_pre2022_alignment"` (`0.60 <= r < 0.80`) | `"weak_regime_mismatch_not_comparable"` (`r < 0.60`) | `"not_assessed_zero_variance"` (`pearson_r: null`).
